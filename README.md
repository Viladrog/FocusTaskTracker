# Focus Task Tracker

Простой трекер задач для ежедневного использования: панель задач у правого края экрана (поверх остальных окон), глобальный хоткей, иконка в трее. Данные хранятся локально на компьютере.

---

## Установка и использование

### Требования

- **Windows 10/11** (64-bit)
- **WebView2 Runtime** — обычно уже установлен в Windows 11; при первом запуске установщик или система могут предложить доустановку

### Установка

1. Скачайте установщик из релиза проекта или соберите его сами (см. раздел [Сборка](#сборка) для разработчиков):
  - **MSI:** `src-tauri/target/release/bundle/msi/`
  - **NSIS:** `src-tauri/target/release/bundle/nsis/`
2. Запустите установщик и следуйте шагам мастера.
3. После установки приложение доступно из меню «Пуск» и в **области уведомлений** (трей).

Файл `**.env` не нужен** — настройка через переменные окружения предназначена только для разработки и сборки.

### Использование


| Действие                 | Как                                                                   |
| ------------------------ | --------------------------------------------------------------------- |
| Показать / скрыть панель | **Ctrl+Shift+Space** (глобально, из любого приложения)                |
| Свернуть окно            | Закрыть окно крестиком — приложение остаётся в **трее**               |
| Полный выход             | Меню иконки в трее → **Выход**                                        |
| Задачи                   | Список в панели; отметка выполнения; данные сохраняются автоматически |
| Ширина панели            | Потянуть левый край окна; ширина запоминается между запусками         |


### Где хранятся данные

Все настройки и задачи — в каталоге данных приложения Windows (не рядом с `.exe`):

```text
%APPDATA%\focus-task-tracker\
  tasks.json      — список задач
  settings.json   — ширина панели и прочие параметры
```

Путь можно открыть в проводнике: `Win+R` → вставить `%APPDATA%\focus-task-tracker` → Enter.

Резервное копирование: скопируйте эту папку целиком.

## Для разработчиков

### Требования

- [Node.js](https://nodejs.org/) (LTS)
- [Rust](https://rustup.rs/) (`stable`, toolchain в PATH)
- [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (для запуска на Windows)
- npm

### Клонирование и запуск

```bash
git clone <url-репозитория>
cd focus
npm install
```

Опционально (только если нужны переменные из шаблона):

```powershell
copy .env.example .env
```

```bash
npm run tauri dev
```

### Сборка

```bash
npm run tauri build
```

Артефакты:


| Файл             | Путь                                              |
| ---------------- | ------------------------------------------------- |
| Исполняемый файл | `src-tauri/target/release/focus-task-tracker.exe` |
| MSI              | `src-tauri/target/release/bundle/msi/`            |
| NSIS             | `src-tauri/target/release/bundle/nsis/`           |


### Переменные окружения

Используются **только при разработке и сборке**, не после установки MSI/NSIS.


| Этап                  | Что происходит                                                                                                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm install`         | `.env` **не** читается                                                                                                                                                        |
| `npm run tauri dev`   | Vite загружает `.env`, `.env.development`, `.env.local`. Tauri может задать `TAURI_DEV_HOST` (см. `vite.config.ts`)                                                           |
| `npm run tauri build` | Перед сборкой выполняется `npm run build`; Vite подхватывает `.env.production` и т.п. Переменные с префиксом `**VITE_`** попадают в фронтенд-бандл (`import.meta.env.VITE_`*) |


Шаблон: `[.env.example](.env.example)` → скопировать в `.env` и раскомментировать нужные строки.


| Переменная       | Назначение                                      |
| ---------------- | ----------------------------------------------- |
| `TAURI_DEV_HOST` | IP/host для HMR при dev на устройстве в сети    |
| `VITE_`*         | Публичные флаги UI на этапе сборки (не секреты) |


Бэкенд (Rust) сейчас **не** читает `.env`; пользовательские данные — в `app_data_dir` (см. выше).

### Разработка и проверка

Окно привязывается к **рабочей области** монитора под курсором при старте; при изменении размера вызывается `reposition_panel`. Имеет смысл проверить второй монитор и масштаб дисплея **125% / 150%** в параметрах Windows.

**IDE:** [VS Code](https://code.visualstudio.com/) + [Tauri](https://marketplace.visualstudio.com/items?itemName=tauri-apps.tauri-vscode) + [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)
